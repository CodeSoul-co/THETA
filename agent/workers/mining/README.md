# Post-model mining tools

This library supplies research primitives, not a solver, semantic annotator or evaluator. Read the public user-requested task/contract separately. Use the original model artifacts and their verified preprocessing provenance; never infer row alignment from shape alone.

1. **Probe topic evidence.** `topic_probe(rows, weights, row_ids, topic, k=5)` returns raw-score representatives, mixed/boundary documents and low-score contrasts. Topic indices are zero-based. Supply actual original document IDs mapped through verified preprocessing provenance. The function checks structural consistency, not provenance truth. Latent scores are not probabilities. Samples are purposive, not population estimates.
2. **Define measurable concepts.** Record candidate hypotheses, positive inclusion, negative exclusion, unknown cases, competing explanations and falsification criteria. Examine negation, sentiment-only near misses, multiple events and scope ambiguity. Do not treat a topic ID or keyword hit as a validated semantic label. Keep alternatives and the selection process.
3. **Persist computation.** `analysis_execute` automatically saves your script and returns its actual path. Reuse it with `runpy.run_path('/work/analysis-scripts/<receipt-id>.py')`. Interpreters are fresh; files persist. Save model-to-document mapping, reviewed definitions and full assignments. Declare expected output paths so missing files are visible. No library function calls a language model or external network.
4. **Partition and compare.** `partition(rows, labels)` requires exactly one `positive`, `negative` or `unknown` label per selected document ID. Missing labels fail rather than silently becoming negatives. `contrast(rows, labels, group_field='...', arms=[[...],[...]], stratify=['...'], min_known=5)` reports denominators, positive/negative/unknown counts, differences, unknown bounds, comparable strata, largest-stratum removal, support concentration and missing metadata. `known = positive + negative`; a minimum known count is not a positive-event threshold. Choose population/arms from the user-authorized contract, not by optimizing the result. This library's output is generic and is not a substitute for a supplied evaluator's exact statistics contract.
5. **Falsify.** Inspect negative and discordant originals, vary defensible thresholds, check duplication/composition, missingness and dropped strata. Report unstable or disappeared relationships and unmodeled documents. Same-corpus exploration does not supply independent confirmation, causal identification or universal generalization. Unknown bounds are not confidence intervals. Do not broaden a definition solely to pass a threshold.
6. **Deliver.** `evidence_spans(rows, selections)` verifies supplied `{doc_id, quote, ...}` records against original text. Save a report, reproducible analysis and evidence/assignments in the user's required format. Run any user-required validator. `analysis_deliver` archives original bytes of plan-required files; it verifies delivery, not truth or an external score. Submit separately when the host provides a submission mechanism. If a finding is unsupported, preserve the failed test and deliver an honest limitation or abstention in the required format.

The library defaults to row fields `doc_id` and `text`; keyword arguments configure these names. It does not select semantic labels, optimize effect sizes, infer missing dates or assume that model weights identify causes. Caller-provided concepts and provenance remain research claims requiring evidence.

Before trusting a scalable text rule, use `audit_sample(rows, labels, per_state=12, seed=...)` to save a reproducible panel across assigned positive, negative and unknown states. Read the raw cases against the frozen definition, record your judgments, then use `audit_disagreements(panel, judgments)` to expose disagreements separately by assigned state. A keyword match is not adjudication. Missing judgments are rejected. Inspect near misses and topic boundaries as additional targeted cases; do not silently fold those into a random-sample accuracy claim. Revise overly broad conditions, preserve the old rule/panel, recompute affected assignments, and disclose remaining ambiguity. This is analyst self-audit, not ground truth or independent semantic validation; no helper calls an LLM.
