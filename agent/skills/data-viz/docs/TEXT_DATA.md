## 如果只有原始文本

先明确展示目标及观察单位：词、短语、句子、文档，还是文档组。保留原文与 ID 的映射，在单独的数据准备脚本中记录分词、去重、过滤、聚合和归一化规则。

- 图 20：只想展示文字时，可以将自己的短标签放入已有位置；这些位置代表排版，不要称为语义距离。如果需要表达语义相似度，则必须从自己的文本表示与降维结果得到坐标，同时更新或关闭网格。记录所用模型/方法、距离定义和随机种子；不得用示例坐标宣称得到新语料的语义结构。
- 图 21：需要先得到一棵真实的层次树。树可来自文本特征聚类，也可来自用户明确提供的主题层次。若用 SciPy 等工具的 linkage 结果，把每次合并转换为 `node,left,right,height`，叶 ID 与标签表对应。不要依据参考词组猜测新数据的合并关系。
- 图 22：整理文档—关键词共现、TF-IDF、主题权重或其他有定义的关联。对每一行说明权重的含义，按文档/词组 ID 与标签表关联。`source_position/target_position` 是线条在带内的排版比例，不是概率；蓝色小方块是路径标记，不是观察值。路径本身不表示时间演变或守恒流量。

已有合适的分析结果时直接使用，不必重新分析原文。缺少必需的语义或层次关系时，说明缺口，选择不依赖该信息的模板或请求补充；不能用模拟值替代真实分析。长句优先使用简短显示标签，把完整文字保留在原始数据映射中。

## 局部删减，保留其余布局

图 20 缺少网格：将 `show_mesh` 设为 `false`，无需提供网格 CSV。删词可直接删除标签行，少量新词可放入空余坐标。

图 21 删除叶节点：同步剪枝，折叠只剩一个子节点的分叉，更新合并表；不能只删标签。替换成非神经数据时同步修改 `heading`。

图 22 缺少传播/覆盖指标：将 `show_dissemination` 设为 `false`，不读取摘要 CSV，文档与词语列的位置保持不变。仅有部分词组摘要也可，只对这些词组画箱体。少量新增关联直接追加流线行；删除关联后避免保留无意义的标签和说明。

## 复刻边界

图 20 的文字与布局是低清图片的近似整理，不能保证逐字恢复。图 21 的词组树按图估读，没有原神经响应数据。图 22 的关联线为固定种子模拟，箱线摘要为估读，不是原文档的真实分析结果。详见各图 `provenance.json`。用于真实数据时保留模板代码与视觉风格，替换数据与领域说明。
