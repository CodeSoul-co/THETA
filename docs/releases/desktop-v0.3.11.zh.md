## 按需生成学术报告

在已完成的结果页点击生成完整分析报告。报告智能体读取已校验的统计、脱敏摘录、模型参数、指标和绘图数据；可补充研究问题。内容依次为数据描述性统计、数据分析、任务分析、建模描述、结论分析。

独立的学术写作提示词要求以完整段落展开严密论证，证据充分时以约 5000–8000 字为目标。报告使用中文，必要的研究局限集中说明，减少重复免责声明。支持分别下载 Markdown 和可检索中文的 PDF。切换页面后继续后台生成；PDF 导出失败可单独重试，无需再次调用模型。点击前不生成，生成时使用已配置的模型接口发送证据，可能产生推理费用。

## 可选的多主题数实验

默认关闭。在分析配置中开启后，可以填写 5、10、15、20 等主题数。每个所选模型分别按各主题数顺序训练，独立保存任务与结果，并标明请求的主题数。最多支持 12 个主题数、48 组模型与主题数组合。各实验使用相同的数据划分设置。HDP 对应截断上限，BERTopic 对应合并目标，实际主题数可能不同。增加实验数量会延长耗时，也可能增加云端嵌入费用。

以上功能由网页工作台与桌面端共同使用。

安装包内置 Python 和计算依赖，不包含模型权重或个人密钥。Windows 可确认重启安装；未签名的 Mac 预览版会下载并校验磁盘映像，再打开供用户覆盖安装。已有项目和设置保留。如果旧版更新器仍提示 HTTP 403，可手动覆盖安装本版本一次。
