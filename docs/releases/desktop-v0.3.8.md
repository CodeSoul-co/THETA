## In-app updates

Install this version once to enable future update checks. Version 0.3.7 and earlier cannot acquire this feature automatically.

- THETA checks for new compatible releases after launch and every six hours. Automatic checking can be disabled in Settings → App updates.
- Use Settings → App updates or the THETA → Check for updates menu to check manually. Download progress and retryable errors are shown in the app.
- Windows downloads verified updates and restarts to install after confirmation. Save your work and wait for analyses to finish before installing.
- The current unsigned Mac preview downloads and verifies the DMG within THETA. Open the downloaded installer, quit THETA, then drag the app into Applications to replace the old version. Native restart-to-install is enabled for Developer ID signed Mac builds.
- Closing THETA alone does not start installation. Projects, credentials and model directories are retained.

Python and compute dependencies are bundled. Model weights remain optional downloads, and API keys must be supplied by each user. These are unsigned preview installers. [SHA-256 checksums](https://github.com/CodeSoul-co/THETA/releases/download/desktop-v0.3.8/SHA256SUMS.txt) are included.
