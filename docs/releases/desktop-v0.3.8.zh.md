## 应用内更新

首次需要安装本版，之后即可使用应用内更新。0.3.7 及更早版本尚无更新模块，无法自动获得此功能。

- 启动后及每六小时自动检查兼容的新版本，可在“设置 → 应用更新”中关闭自动检查。
- 可通过“设置 → 应用更新”或“THETA → 检查更新”菜单手动检查，应用内显示下载进度，失败后可重试。
- Windows 下载并校验更新，确认后退出并安装，随后重新启动。安装前请先保存工作并等待分析完成。
- 当前未正式签名的 Mac 预览版会在应用内下载并校验 DMG；打开已下载的安装包，退出 THETA，再拖入“应用程序”替换旧版。使用 Developer ID 正式签名的 Mac 构建可启用原生重启安装。
- 普通退出不会触发安装；项目、密钥和模型目录会保留。

已内置 Python 与计算依赖；模型权重按需另行下载，密钥由用户自行填写。本版仍为未正式签名的预览版，提供 [SHA-256 校验文件](https://github.com/CodeSoul-co/THETA/releases/download/desktop-v0.3.8/SHA256SUMS.txt)。
