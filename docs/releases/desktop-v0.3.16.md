# THETA 0.3.16 — macOS preview

**English** | [中文](https://github.com/CodeSoul-co/THETA/blob/main/docs/releases/desktop-v0.3.16.zh.md)

[Download for macOS Apple Silicon](https://github.com/CodeSoul-co/THETA/releases/download/desktop-v0.3.16/THETA-0.3.16-mac-arm64.dmg)

Research datasets and directly imported files are now isolated by project. Uploading data preserves the current conversation, and switching projects prevents delayed responses from replacing the active project's data.

Training results are marked complete only when the analysis artifacts are ready. While results are being prepared, the interface continues to show progress. The research assistant starts collapsed and opens after a successful upload.

This release includes bundled Python and compute dependencies. Personal API keys, projects and model weights are not included. Existing local projects and settings are retained when upgrading. The release includes the ZIP archive, update metadata and checksums used by the desktop updater.

This release provides macOS Apple Silicon packages only. The application is ad-hoc signed, without Apple Developer ID signing or notarization; macOS security warnings may still appear. Intel Mac and Windows packages are not included in this release.
