# THETA 0.3.17

中文 | [English](desktop-v0.3.17.md)

- Agent 保持本地，默认本地训练。“设置 → 计算资源”新增远程服务地址、密钥和每个实验费用上限。
- 对话和手动模式共用计算选择；远程训练前明确确认数据上传与费用上限。
- 接收轮次、批次与嵌入进度；完整结果、划分产物和图表下载校验完成后才显示完成。
- 切换设置不改变已有远程任务的服务绑定；已下载结果支持本地浏览及分析报告生成。
- 用户凭据仅保存在本机，安装包不包含个人配置；保留原有项目与设置。

远程训练需要兼容 THETA Worker v1 的服务，本版本不包含已部署的商业服务。实际供应商的计费和计算设施需单独验收，详见[接入说明](../worker-api.zh.md)。

预览安装包尚未正式签名或公证。已内置 Python 和计算依赖，模型权重按需配置。
