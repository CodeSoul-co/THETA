## 有图表证据的学术报告

报告按“提出研究判断、展示一个必要图表、深入解释数值与研究含义、衔接下一个论点”的顺序展开。图表前后须有实质性分析段落，不允许连续堆放图表或用清单代替论证。插入的图片和表格来自本次训练的已校验产物。图表具备固定编号、标题、来源和数据范围，报告智能体据此引用具体数值、展开解释并支撑结论，分别说明全量、训练、验证和测试数据。表格摘录明确展示范围，完整原始数据表包含在图文包中。缺少的图表不会凭空生成或自动重新绘制。

修正重复章节标题与混乱的标题层级。文档导出支持表格、列表和本地图片，图与图注共同排版，长表分段时保留表头。可下载独立的 PDF、Markdown 正文，以及包含正文、图片和原始表格的压缩包。编辑 Markdown 时，请保留同级 assets 文件夹。

已有报告可以主动点击重新生成，使用当前配置的模型接口。报告仍然只在点击后异步生成；正文生成失败时保留旧报告，单独重试 PDF 导出不会再次调用模型。网页与桌面端同步使用这些改进。

安装包内置 Python 与计算依赖，不包含模型权重或个人密钥。升级时保留已有项目与设置。
