研究数据与直接导入的文件按项目隔离。上传数据后保留当前对话，切换项目时不会再被旧请求返回的数据覆盖。

分析结果准备就绪后才显示已完成；生成结果期间继续显示处理进度。研究助手默认收起，成功上传数据后自动展开。

安装包内置 Python 和计算依赖，不包含个人密钥、项目数据或模型权重。升级保留已有项目和配置。同时提供应用更新所需的压缩包、更新清单及校验文件。

本次仅发布 Apple 芯片 Mac 安装包。应用采用本地签名，尚无 Apple 开发者签名及公证，系统仍可能显示安全提示。本次不含 Intel Mac 或 Windows 安装包。
