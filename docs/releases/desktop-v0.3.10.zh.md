## 模型选择

- 新建分析默认选中 LDA，并显示推荐标记；已有项目保存的模型选择保留。
- 传统模型排在前面，THETA 移到模型列表末尾，并明确标注“测试版”。
- 对话中的默认模型建议优先采用无需下载嵌入模型、易于解释的 LDA，同时尊重用户指定的模型和研究需要。
- 网页与桌面端同步使用这些调整。

## 数据集结果与训练修复

- 结果页统一切换全量、训练、验证、测试集，指标、可视化、绘图数据与引用同步使用对应记录。已有划分的任务可重新生成图表，无需重新训练。
- 提高平均权重的显示精度，并显示与全量均值的差；NVDM 使用可为负数的潜在坐标说明与图形，不再误标为占比。
- 修复 THETA 冻结嵌入模式把损失固定为零、跳过主题模型更新的问题；小样本与末尾批次不再被默认丢弃。该模式保持嵌入冻结，使用真实重建损失与 KL 正则训练主题模型。旧版零损失任务需要重新训练，补图无法修复未训练的模型。
- GitHub 更新接口不可用或限流时，改用同一仓库的公开发行订阅与校验清单，安装包仍需通过大小及 SHA-256 校验。

0.3.8 起的已安装版本可在“设置 → 应用更新”检查此版本。自动检查发现兼容新版后会弹出下载通知。Windows 支持确认后重启安装；当前未正式签名的 Mac 预览版会下载、校验并打开磁盘映像，需要替换“应用程序”中的旧版，不会静默替换。项目与配置保留。

安装包内置 Python 与计算依赖，不包含模型权重或用户密钥。
